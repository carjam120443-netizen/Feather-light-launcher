# 🪶 Feather Light Launcher

A lightweight, battery-conscious Android launcher designed to keep your home screen simple, fast, and efficient.

## 🎯 Goal

Feather Light Launcher aims to provide a clean Android home-screen experience without unnecessary background work, heavy animations, telemetry, or resource-hungry features.

The goal isn't to magically increase battery capacity — it's to make the launcher itself use as few resources as reasonably possible.

## ✨ Planned Features

- 🏠 Lightweight home screen
- 📱 Installed app drawer
- 🔎 Fast app search
- ⭐ Favorite apps
- 🕐 Clock
- 🔋 Battery indicator
- 🌙 Dark mode
- 🎨 Simple customization
- ⚡ Battery-conscious animations
- 💤 Minimal background activity
- 🚫 No unnecessary telemetry

## 🚧 Status

**Early development** — the project is currently being built from the ground up.

Features and design may change as development continues.
